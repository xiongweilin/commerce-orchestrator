**状态：已冻结的历史前身。**

本仓库作为参考快照保留，用于记录 Commerce 工作流设计、effect reconciliation、Shopify/Odoo 集成、DBOS 编排和 domain-completion 实验。

不要把本仓库中的 Compose 文件、runbook、依赖版本、API 形态或服务拓扑当作当前 AIOS 的运维指南。

当前共享的语义/运行时权威所有者：

- [AIOS monorepo](https://github.com/xiongweilin/aios)
- [World Runtime](https://github.com/xiongweilin/aios/tree/main/world-runtime)
- [Semantic Language](https://github.com/xiongweilin/aios/tree/main/semantic-language)
- [guide](https://github.com/xiongweilin/guide)

本快照不再继续功能开发。未来新的 Commerce 实现必须基于当前有效的 AIOS runtime 重新建立契约，而不是继续在这棵代码树上扩展。
