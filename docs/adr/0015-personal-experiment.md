# ADR-0015：项目定位为个人试验（撤销生产提升条款）

- **Status**: Accepted
- **Date**: 2026-08-13

## Context

项目此前在 ADR-0010 中定义了「首个生产提升条件」等上线门禁。实际上项目自始以模拟数据 +
Shopify 开发店 + Odoo 19 沙盒运行，无真实用户与真实订单，也不存在生产提升对象；门禁表述与
运行形态不一致，容易造成「生产待提升」的误读。

## Decision

- 项目定位为**个人全栈试验**：以模拟数据 + Shopify 开发店 + Odoo 19 沙盒验证跨系统工作流
  编排、候选/审批、幂等、effect ledger 与对账；无真实用户与真实订单，不设生产提升路径，
  持续运行供学习与迭代。
- **撤销 ADR-0010 的「首个生产提升条件」条款**（ADR-0010 原文保留，头部标注
  `Superseded-by（生产提升条款）: ADR-0015`）。
- 不再设影子运行、正式店切换、业务负责人验收等生产相关门禁。
- 故障注入与性能检查等自动化工程质量门禁**保留**，作为工程回归基准（不承载生产上线语义）；
  已做单机性能冒烟，不做生产规模压测。

## Consequences

**正面**：文档与运行形态一致——个人试验栈持续运行；门禁表述不再造成「生产待提升」的误读。

**负面/约束**：ADR-0010 中的性能门禁与生产提升条件不再作为生产验收执行；运行栈继续作为
沙盒使用，不对外提供业务服务。
